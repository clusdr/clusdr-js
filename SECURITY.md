# Security Policy

Do not file a public issue for a vulnerability in this SDK.

## Report

Use [GitHub private vulnerability reporting](https://github.com/clusdr/clusdr-js/security/advisories/new).

If the bug is in the daemon, report it on [clusdr/clusdr](https://github.com/clusdr/clusdr/security/advisories/new) instead.

Include the package version (`npm show clusdr version` or the git tag), what you did, and what happened.

## Support window

Same train as the daemon (**v1alpha1**). We patch the current release. There is no long-term support window yet.
